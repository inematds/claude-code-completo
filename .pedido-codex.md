## O que o kit faz
Junta vários vídeos curtos (16:9) num UM vídeo longo de curso, com um cartão de capítulo de 3 s antes de cada vídeo, áudio normalizado, e gera os capítulos no formato do YouTube e a descrição pronta. ffmpeg local, sem IA.

## 1. `ferramentas/montar_curso.py` (Python 3.10+, só stdlib + Pillow; PyYAML opcional)
Uso:
```
python3 ferramentas/montar_curso.py curso/curso.json --saida saida/curso.mp4 [--cartao-s 3] [--largura 1920 --altura 1080 --fps 30] [--so-capitulos] [--manter-temp]
```
- Entrada: JSON ou YAML (`.yaml/.yml`; se o PyYAML não estiver instalado, erro claro dizendo para usar JSON ou `pip install pyyaml`). Formato: `{"titulo": str, "descricao_topo": str?, "descricao_fim": str?, "capitulos": [{"arquivo": str, "titulo": str, ...campos extras ignorados}]}`. Também aceitar a lista pura de capítulos. `arquivo` aceita `~` e caminho relativo ao arquivo de entrada.
- Valida antes de render: arquivo existe, tem vídeo (ffprobe), duração > 0; título não vazio. Erro claro com o número do capítulo. Avisos (não erro) para as regras do YouTube: menos de 3 capítulos; capítulo com menos de 10 s (contando o cartão).
- Cartão de capítulo (Pillow → PNG → ffmpeg 3 s com áudio silencioso): fundo preto `#0c0c10`; no alto à esquerda uma etiqueta pequena "CAPÍTULO N de T" em amarelo `#FACC15`; o título do capítulo grande em branco, centralizado na vertical, quebrando linha para caber em 80% da largura (diminui a fonte se passar de 3 linhas); um filete amarelo `#FACC15` curto embaixo do título; o título do curso pequeno em cinza claro no rodapé. Fonte: `ferramentas/fontes/Sora.ttf` (fonte variável: use `set_variation_by_name('ExtraBold')` no título e `'SemiBold'` no resto); se a fonte faltar, cai na DejaVuSans-Bold com aviso. Nada de logo.
- Cada vídeo é re-encodado para o mesmo formato (scale+pad para LxA mantendo proporção, fps fixo, `yuv420p`, H.264 `-crf 20 -preset medium`, AAC 48 kHz estéreo 192k) com `loudnorm=I=-16:TP=-1.5:LRA=11` (passo único basta). Vídeo sem áudio ganha áudio silencioso. Depois concat demuxer (`-c copy`) num MP4 com `+faststart`.
- Capítulos: o capítulo N começa no início do SEU cartão. O primeiro é `00:00`. Formato `MM:SS Título` (ou `H:MM:SS` quando o total passar de 1 h). Use as durações REAIS dos segmentos já re-encodados (ffprobe), não as dos originais, para não escorregar. Grava `<saida sem extensão>-capitulos.txt` e `<saida sem extensão>-descricao.txt` (= descricao_topo + linha em branco + "Capítulos:" + capítulos + linha em branco + descricao_fim; o que faltar é omitido).
- `--so-capitulos`: não renderiza; calcula os tempos pelas durações dos originais + cartões e imprime/grava os dois .txt (marcar no topo da saída do terminal que é estimativa).
- Imprime no fim: duração total (min:s), número de capítulos, caminhos gravados. Código de saída 0 só se o MP4 existir e a duração conferida por ffprobe bater com a soma dos segmentos (±1 s); senão 1.
- Pasta temporária com `tempfile`, apagada no fim (a não ser `--manter-temp`). Checa se `ffmpeg`/`ffprobe` existem (erro claro se não).

## 2. Testes `testes/test_montar_curso.py` (pytest)
- Gera 3 vídeos sintéticos curtos com `ffmpeg -f lavfi testsrc` + `sine` (2–4 s, tamanhos diferentes: 1280x720, 1920x1080, 640x360; um deles SEM áudio) em `tmp_path`, com `--cartao-s 1` e 640x360 para ser rápido.
- Confere: MP4 existe; resolução de saída; tem stream de áudio; duração ≈ soma (originais + cartões) ±1 s; capitulos.txt tem 3 linhas, a 1ª começa com `00:00`, tempos crescentes, cada linha bate com a soma acumulada ±1 s; descrição contém "Capítulos:" e os títulos.
- Erros: arquivo inexistente → saída ≠ 0 e mensagem com o número do capítulo; título vazio → erro.
- Formato de tempo: função pura testada (`0→00:00`, `65→01:05`, `3725→1:02:05`).
- Cartão: gera o PNG e confere tamanho e que o pixel do canto é `#0c0c10`.
- Entrada YAML (pular o teste se não houver PyYAML) e lista pura.
- `--so-capitulos` não cria MP4.
- Pule tudo com mensagem clara se não houver ffmpeg.
