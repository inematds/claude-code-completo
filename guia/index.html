Em resumo

O Claude Code é o assistente de IA da Anthropic que trabalha nos arquivos do seu computador: lê, escreve, organiza e roda tarefas por você. Este é um curso completo em capítulos, num vídeo só e grátis, que vai do mapa do Claude até agentes que provam o que fazem, trabalham com segurança e rodam sozinhos. Cada capítulo tem um guia com o passo a passo e um prompt pronto para copiar. Para assistir, basta o navegador. O repositório traz também a ferramenta que montou este vídeo, para você juntar os seus próprios vídeos curtos num curso longo.

Capítulos

Do básico ao avançado, na ordem

Clique no tempo para abrir o curso naquele ponto. Cada capítulo tem o guia completo do assunto (grátis) e um prompt pronto. Os prompts dos capítulos 1, 2 e 5 vão no chat do Claude (no site ou no app); os outros, no Claude Code aberto na pasta do seu trabalho, onde estão os arquivos que ele vai ler.

Nunca abriu o Claude Code? Ele vem no app do Claude para computador (planos pagos) e também roda no terminal. O passo a passo oficial de instalação está em code.claude.com/docs, e o capítulo 3 mostra o que ele faz no seu computador.

O agente que aprende com o erro

Os degraus para o agente parar de repetir o mesmo erro: anotar a falha, separar erro de pedido de erro de máquina e transformar a lição numa trava automática.

Guia do capítulo →Vídeo avulso
Prompt pronto

Se não existir, crie um FALHAS.md com uma linha por erro que eu corrigir daqui para a frente. Depois mostre os erros que mais voltam e proponha, para cada um, uma trava automática (um teste, um hook ou uma checagem) em vez de mais uma regra escrita. Não aplique nada sem eu aprovar.

Palavras que aparecem aqui

Claude Code
o programa da Anthropic em que o Claude trabalha direto nos arquivos do seu computador, no terminal ou no app.
Prompt
o pedido que você escreve para a IA.
Agente
uma IA que não só responde: executa passos sozinha (abre arquivos, roda comandos) até terminar a tarefa.

a pasta onde estão os arquivos que o Claude Code vai ler e mexer; ele só enxerga o que está nela.
Hook
uma checagem automática que o Claude Code roda antes ou depois de uma ação.
Timer, cron
agendadores que rodam uma tarefa sozinhos, na hora marcada.
JSON

Assinatura

E com o kit abaixo você monta o seu curso longo com os seus vídeos.
Parte técnica

O kit: para quem quer montar o próprio curso longo

Daqui para baixo é a parte técnica: juntar os seus vídeos curtos num vídeo longo com capítulos. Você não precisa desta parte para assistir o curso.

O que é

Uma ferramenta local, sem IA

O montar_curso.py é a mesma ferramenta que montou o curso acima. Você dá a lista de vídeos e títulos; ele devolve o vídeo longo, os capítulos e a descrição.

Cartão de capítulo

3 segundos de tela preta com "CAPÍTULO N de T" e o título em amarelo e branco antes de cada vídeo.

Som no mesmo volume

Cada vídeo passa por normalização de áudio, para ninguém precisar mexer no volume entre um capítulo e outro.

Capítulos do YouTube

Gera a lista "00:00 Título" com os tempos reais do vídeo final e a descrição pronta para colar.

Como funciona

Da lista ao vídeo longo

Lista de vídeos (JSON ou YAML)→ Confere cada arquivo→ Cartão + vídeo no mesmo formato→ Junta tudo→ MP4 + capítulos + descrição

Todo vídeo é convertido para o mesmo tamanho (1920×1080 por padrão, com bordas se a proporção for outra), 30 quadros por segundo e áudio a −16 LUFS. O capítulo começa no próprio cartão. No fim, a ferramenta confere que a duração do MP4 bate com a soma das partes (até 1 s de diferença) e só então sai com sucesso.

Pré-requisitos

O que você precisa

Tudo roda no terminal, a janela de comandos do computador: no Mac, abra o app Terminal; no Linux, Ctrl+Alt+T. Os comandos são para Mac e Linux; no Windows, use o WSL (o Ubuntu dentro do Windows) e siga como no Linux.

Python 3.10 ou mais novo

Confira com o comando abaixo. Se não tiver, baixe em python.org.

python3 --version

ffmpeg

O programa que junta e converte os vídeos. Ubuntu/WSL: sudo apt install ffmpeg. Mac: brew install ffmpeg.

ffmpeg -version

O kit

Com o git, o comando abaixo. Sem o git: no GitHub do kit, botão "Code" → "Download ZIP", e descompacte.

git clone https://github.com/inematds/claude-code-completo
cd claude-code-completo

Instale o Pillow num ambiente só do kit

O Pillow desenha os cartões de capítulo. Instale num ambiente separado (venv), que funciona até nos sistemas que bloqueiam o pip direto. Dentro da pasta do kit:

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt   # na próxima vez, basta o source .venv/bin/activate
Guia de uso · passo a passo

Em 5 minutos

1

Rode no exemplo

Crie três vídeos de teste e monte um curso de 45 segundos com eles, para ver o resultado antes de usar os seus:

python3 ferramentas/videos_de_teste.py
python3 ferramentas/montar_curso.py exemplos/meu-curso.json --saida saida/curso.mp4
2

Escreva a lista do seu curso

Copie o exemplo para a pasta do kit e abra a cópia num editor de texto (TextEdit, Bloco de Notas ou VS Code). Troque o título, as descrições e, em cada capítulo, o arquivo e o título. Use o caminho completo de cada vídeo (ex.: ~/Videos/aula1.mp4): os caminhos curtos do exemplo (videos/aula1.mp4) só valem dentro da pasta exemplos/. Os nomes dos campos (titulo, capitulos, arquivo) ficam como estão: a ferramenta só lê esses.

cp exemplos/meu-curso.json meu-curso.json
# {"titulo": "...", "descricao_topo": "...", "descricao_fim": "...",
#  "capitulos": [{"arquivo": "~/Videos/aula1.mp4", "titulo": "Primeiros passos"}, ...]}
3

Confira os tempos antes de renderizar

Sem gastar tempo de render, veja os capítulos estimados e os avisos do YouTube (pelo menos 3 capítulos, cada um com 10 s ou mais):

python3 ferramentas/montar_curso.py meu-curso.json --saida saida/meu-curso.mp4 --so-capitulos
4

Monte o vídeo longo

Um curso de 30 minutos leva da ordem de meia hora num computador comum. A saída vem com três arquivos:

python3 ferramentas/montar_curso.py meu-curso.json --saida saida/meu-curso.mp4
# saida/meu-curso.mp4 · saida/meu-curso-capitulos.txt · saida/meu-curso-descricao.txt
5

Publique com os capítulos

Suba o MP4 no YouTube e cole o conteúdo do -descricao.txt na descrição. O YouTube transforma as linhas "00:00 Título" nos capítulos da barra do vídeo.

cat saida/meu-curso-descricao.txt
6

Ajustes e testes

Mude a duração do cartão, o tamanho ou os quadros por segundo; e rode os testes do próprio kit (pedem o pytest):

python3 ferramentas/montar_curso.py meu-curso.json --saida saida/meu-curso.mp4 --cartao-s 4 --largura 1280 --altura 720
pip install pytest
python3 -m pytest -q   # 10 testes com vídeos sintéticos (9 + 1 pulado sem o PyYAML)
