In summary

Claude Code is Anthropic's AI assistant that works with the files on your computer: it reads, writes, organizes, and runs tasks for you. This is a complete course with chapters, in a single free video that takes you from the Claude map to agents that prove what they do, work safely, and run on their own. Each chapter has a step-by-step guide and a ready-to-copy prompt. All you need to watch is a browser. Technical details

The kit: for anyone who wants to build their own long-form course

From here on, this is the technical part: combining your short videos into one long video with chapters. You not needed from this section to watch the course.

What it is

A tool local, no AI

O montar_curso.py it's the same tool that put together the course above. You give it the list of videos and titles; it returns the long-form video, chapters, and description.

Chapter card

3 seconds of a black screen with "CHAPTER N OF T" and the title in yellow and white before each video.

Consistent audio volume

Each video goes through audio normalization so no one has to adjust the volume between chapters.

YouTube chapters

Generates the "00:00 Title" list with the actual timestamps from the final video and a description ready to paste.

How it works

From the list to long-form video

Video list (JSON or YAML)→ Checks each file→ Card + video in the same format→ Put it all together→ MP4 + chapters + description

Every video is converted to the same size (1920×1080 by default, with borders if the aspect ratio differs), 30 frames per second, and audio at −16 LUFS. The chapter starts on the card itself. At the end, the tool checks that the MP4 duration matches the sum of the parts (within 1 second) and only then reports success.

Prerequisites

What you need

Everything runs in the terminal, your computer's command window: on a Mac, open the Terminal app; on Linux, press Ctrl+Alt+T. The commands are for Mac and Linux; on Windows, use WSL (Ubuntu inside Windows) and follow the Linux steps.

Python 3.10 or newer

Check with the command below. If you don't have it, download it from python.org.

python3 --version

ffmpeg

The program that joins and converts the videos. Ubuntu/WSL: sudo apt install ffmpeg. Mac: brew install ffmpeg.

ffmpeg -version

The kit

With git, the command below. Without git: on the kit's GitHub page, click "Code" → "Download ZIP" and unzip it.

git clone https://github.com/inematds/claude-code-completo
cd claude-code-completo

Install Pillow in an environment just for the kit

Pillow draws the chapter cards. Install it in a separate environment (venv), which works even on systems that block pip directly. Inside the kit folder:

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt   # next time, just run source .venv/bin/activate
User guide · step by step

In 5 minutes

1

Run the example

Create three test videos and build a 45-second course with them, to see the result before using your own:

python3 ferramentas/videos_de_teste.py
python3 ferramentas/montar_curso.py exemplos/meu-curso.json --saida saida/curso.mp4
2

Write your course list

Copy the example into the kit folder and open the copy in a text editor (TextEdit, Notepad or VS Code). Replace the title, the descriptions and, in each chapter, the file and the title. Use the full path of each video (e.g. ~/Videos/lesson1.mp4): the short paths in the example (videos/aula1.mp4) only work inside the exemplos/ folder. Keep the field names as they are (titulo, capitulos, arquivo, in Portuguese): the tool only reads those.

cp exemplos/meu-curso.json meu-curso.json
# {"titulo": "...", "descricao_topo": "...", "descricao_fim": "...",
#  "capitulos": [{"arquivo": "~/Videos/lesson1.mp4", "titulo": "First steps"}, ...]}
3

Check the timings before rendering

Without spending time rendering, see the estimated chapters and YouTube warnings (at least 3 chapters, each 10 seconds or longer):

python3 ferramentas/montar_curso.py meu-curso.json --saida saida/meu-curso.mp4 --so-capitulos
4

Build the long video

A 30-minute course takes about half an hour on an ordinary computer. The output includes three files:

python3 ferramentas/montar_curso.py meu-curso.json --saida saida/meu-curso.mp4
# saida/meu-curso.mp4 · saida/meu-curso-capitulos.txt · saida/meu-curso-descricao.txt
5

Publish with chapters

Upload the MP4 to YouTube and paste the contents of -descricao.txt in the description. YouTube turns lines like "00:00 Title" into chapters on the video progress bar.

cat saida/meu-curso-descricao.txt
6

Settings and tests

Change the card duration, size, or frame rate; and run the kit's own tests (they require pytest):

python3 ferramentas/montar_curso.py meu-curso.json --saida saida/meu-curso.mp4 --cartao-s 4 --largura 1280 --altura 720
python3 -m pytest -q   # 10 tests with synthetic videos
